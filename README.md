# 🏠 House Price Prediction

A full-stack machine learning web application that predicts house prices based on
area (sq ft) and number of rooms.

- **Backend**: Flask REST API
- **Frontend**: Streamlit
- **ML Model**: Linear Regression (scikit-learn)
- **Dataset**: `data/house_price.csv` (47 samples — area, rooms, price)

## Quickstart

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the model
```bash
python train_model.py
```
This reads `data/house_price.csv`, trains a Linear Regression model on `area`
and `rooms` to predict `price`, prints evaluation metrics (MAE, RMSE, R²),
and saves the model to `model/model.pkl`.

### 3. Start the Flask backend
```bash
cd backend
python app.py
```
The API runs at `http://localhost:5000` with these endpoints:

| Method | Endpoint      | Description                              |
|--------|---------------|-------------------------------------------|
| GET    | `/health`     | Service status                            |
| GET    | `/model-info` | Model type, features, and metrics         |
| POST   | `/predict`    | Body: `{"area": 1500, "rooms": 3}` → predicted price |

### 4. Start the Streamlit frontend
In a new terminal:
```bash
cd frontend
streamlit run ui.py
```
Open the URL Streamlit prints (usually `http://localhost:8501`), enter an
area and number of rooms, and click **Predict Price**.

## Model

A simple Linear Regression model is trained on two features — `area` and
`rooms` — to predict `price`. On a held-out test split it achieves an R²
of ~0.95, meaning the two features explain most of the variance in price
for this dataset.
